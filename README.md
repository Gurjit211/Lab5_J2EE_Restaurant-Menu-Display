# J2EE_Lab5_
Name: Gurjit Singh   Sid:N01634963  Lab5 Restaurant Menu Display Humber North ITS .

This project is a simple restaurant menu management web application developed as part of a learning exercise. The application demonstrates the use of Jakarta EE Servlets, Hibernate ORM, and a MySQL database within a Maven project structure. The project also includes a basic front end built with JSP, JavaScript, and CSS.

Key features include:

Fetching and displaying menu items from a database.

Implementing CRUD operations: view, search, edit, and delete menu items.

Using AJAX to handle dynamic interactions between the front end and the server.

Managing database connectivity and object-relational mapping through Hibernate.

The application runs on Apache Tomcat and was developed using Intellij Ultimate and NetBeans IDE with Maven for dependency management.
